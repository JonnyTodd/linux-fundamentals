# The Northstar Incident

Northstar has asked you to investigate suspicious activity involving a former worker's account and a finance workstation.

You will inspect prepared evidence from three sources:

- a suspicious email;
- authentication logs; and
- a saved process snapshot from the workstation.

The lab is fictional. The addresses use reserved training domains and IP ranges. Do not visit links or investigate addresses outside the supplied directory.

## Your working rules

1. Work only inside `~/cyber-lab2/northstar-incident`.
2. Preserve the supplied source files.
3. Save your findings in the `evidence` directory.
4. Separate observed facts from your interpretation.
5. Correlate several indicators before declaring an incident.

## Help with unfamiliar commands

Use either of these methods before running a command you do not understand:

```bash
grep --help
man grep
```

Inside a manual page, type `/word` to search, `n` for the next match and `q` to quit. Some small training images do not include every manual page. Use `command --help` when `man` is unavailable.

Select **START** when the terminal is ready.
