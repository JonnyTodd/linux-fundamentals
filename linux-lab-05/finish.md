# Ubuntu administration lab complete

You have completed a small but realistic administration workflow:

- collected a system baseline;
- distinguished package catalogue updates from package installation;
- installed and verified a package;
- identified a running process and listening TCP port;
- retrieved a local service response;
- created and inspected UFW policies and rules safely;
- analysed unsuccessful web requests;
- created a compressed administration backup;
- generated and verified a SHA-256 checksum;
- assembled current system evidence into a final audit report.

## The habit to retain

```text
Inspect → plan → change → verify → record
```

On a production server, every administrative change should have a reason, a deliberately limited scope and evidence that the intended result was achieved.
