# Step 1 — Identify the account

Begin with the current account:

```bash
whoami
id
groups
```

`id` shows the user ID, primary group and any supplementary groups. `groups` gives a shorter list of group memberships.

Move to the prepared environment:

```bash
cd ~/linux-lab3/company
pwd
ls
cat README.txt
```

There is no CHECK on this step. Continue when you can identify the account you are using and the directories prepared for the systems check.
