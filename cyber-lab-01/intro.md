# The Northstar Security Audit

Northstar Services has asked you to carry out an initial security audit of a prepared Ubuntu system.

You will inspect files and system evidence, then decide which problems matter most. You are working inside a disposable training environment containing fictional data.

## Your rules of engagement

- Inspect only the files inside `~/cyber-lab1/northstar`.
- Do not delete, move or alter the original evidence.
- Store your notes inside the supplied `evidence` directory.
- Treat every password and personal record as fictional training data.

This lab explains each new command before you use it. Read the explanation first, predict what the command will do, and then run it.

## Getting help with a command

Most commands can display a short help page:

```bash
find --help
```

For a fuller manual, use `man` followed by the command name:

```bash
man find
```

Inside a manual page:

- type `/name` to search for the word **name**;
- press `n` to move to the next match;
- press `q` to leave the manual.

If a manual page is unavailable in the temporary environment, use `command --help` instead. Replace `command` with the command you are investigating.

Select **START** when you are ready to begin.
