# Audit complete

You have completed Northstar's initial security audit.

You have:

- identified assets and vulnerabilities;
- gathered evidence without changing the source material;
- connected findings to confidentiality, integrity and availability;
- calculated risk from likelihood and impact; and
- prioritised controls using evidence rather than guesswork.

You have also practised reading unfamiliar commands rather than treating them as recipes. Keep using:

```bash
command --help
man command
```

Replace `command` with the command you need to investigate. In a manual page, use `/word` to search, `n` for the next match and `q` to quit.

## Keep the chain clear

```text
asset → threat → vulnerability → impact → risk → control
```

In Session 2, you will use logs and other evidence to recognise suspicious activity and distinguish an event from a possible incident.
