# Linux Fundamentals — Lab 1: First Steps

Welcome to your first practical Linux lab.

You are working in a **real Ubuntu Linux environment** running in the browser. The machine is temporary, so this is a safe place to experiment.

## By the end of the lab you will be able to

- identify the user and system you are working on;
- find your current location in the filesystem;
- list files and directories;
- move between directories;
- create files and directories;
- copy, rename and remove files;
- reveal hidden files.

## Important

Linux commands and filenames are **case-sensitive**.

For example:

```text
Notes.txt
notes.txt
NOTES.txt
```

can all refer to different files.

Also remember that `rm` normally deletes files directly — there is no normal Recycle Bin.

Select **START** when you are ready.
