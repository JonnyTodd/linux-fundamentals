# Step 1 — Meet your Linux system

The blinking cursor is your **command prompt**. You type commands here and press **Enter** to run them.

Try these commands one at a time:

```bash
whoami
```

`whoami` displays the user account you are currently using.

```bash
hostname
```

`hostname` displays the name of the computer.

```bash
uname -s
```

`uname -s` displays the kernel/system name.

Now find your current location:

```bash
pwd
```

`pwd` means **print working directory**.

Finally, list the contents of your current directory:

```bash
ls
```

## Think

1. Which user are you logged in as?
2. What does `pwd` report?
3. What system name is returned by `uname -s`?

There is no CHECK on this first step because you are inspecting the system rather than changing it.

When you are comfortable with the commands, continue.
