# Step 3 — Create files and directories

Move into your new directory:

```bash
cd ~/linux-lab1/training/practice
```

Create an empty file:

```bash
touch notes.txt
```

Now create another empty file called:

```text
commands.txt
```

List the directory contents to confirm both files exist.

## View an existing text file

Linux provides many ways to inspect text. One of the simplest is `cat`.

Try:

```bash
cat ../welcome.txt
```

The `..` means “one directory above the current directory”, so this displays the `welcome.txt` file from the training directory.
