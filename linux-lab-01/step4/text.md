# Step 4 — Copy and rename files

The `cp` command copies files.

From your `practice` directory, copy the welcome file into the current directory:

```bash
cp ../welcome.txt welcome-copy.txt
```

List your files:

```bash
ls
```

The `mv` command can move files, but it is also commonly used to **rename** them.

Rename:

```text
notes.txt
```

to:

```text
linux-notes.txt
```

Use this pattern:

```text
mv old-name new-name
```

## Your task

Your `practice` directory should now contain:

```text
commands.txt
linux-notes.txt
welcome-copy.txt
```

Select **CHECK** when complete.
