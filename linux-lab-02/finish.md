# Lab 2 complete

You have used Linux commands to turn large text files into useful evidence.

## Commands used

```text
cat        display a whole text file
head       show the beginning of a file
tail       show the end of a file
wc -l      count lines
grep       display matching lines
grep -c    count matching lines
grep -n    show matching line numbers
grep -i    ignore upper/lower case
>          write output, replacing the destination
>>         append output to the destination
```

You also applied the troubleshooting routine from Lab 1: `pwd`, `ls`, read the error and check the path.
