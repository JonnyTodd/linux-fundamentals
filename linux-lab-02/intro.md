# Linux Fundamentals — Lab 2: Files and Text

In Lab 1, you learnt how to find and manage files. This time the question changes:

> **What useful information is inside those files?**

You are joining the support team for a small organisation. The temporary Linux machine contains staff records and three server logs. You will preview them, count records, search for important events and create short evidence reports.

## By the end of the lab you will be able to

- preview the beginning and end of long files;
- count lines in a file;
- search for matching text;
- count search results;
- write command output to a new file;
- append more output without deleting the existing contents;
- investigate repeated failed logins.

## Important

The `>` symbol **replaces the contents** of its destination file. The `>>` symbol adds new output to the end.

Select **START** when you are ready.
